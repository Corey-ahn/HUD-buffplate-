# HUD (buffplate)

ArcheRage 애드온입니다. 나 · 대상 · 파티원의 **버프 · 디버프, 스킬 · 물약 쿨타임, CC, 전투 자원 게이지**를 **머리 위에** 띄웁니다.
명령어를 외울 필요 없이 창에서 미리보기를 보며 고르기만 하면 됩니다.

## 설치

1. 오른쪽 **Releases** 에서 최신 `buffplate-버전.zip` 을 받습니다.
2. 압축을 풀면 나오는 `buffplate` 폴더와 `globals` 폴더를 둘 다 아래 폴더에 넣습니다.
   ```
   문서\ArcheRage\Addon\
   ```
   (이미 있으면 폴더째 덮어쓰세요)
3. 게임을 켜거나, 이미 켜져 있으면 다시 접속합니다.
4. 화면에 HUD 아이콘이 생깁니다. 끌어서 원하는 곳에 두세요.
   - [통합 일정표](https://github.com/Corey-ahn/Rage-DayPlan) 를 쓰고 있으면 아이콘 대신 일정표의 **[HUD]** 버튼으로 엽니다.

## 쓰는 법

아이콘(또는 일정표 [HUD])을 누르면 설정 창이 열립니다.

- **위 버튼 [나] [대상] [파티 및 공대]** — 어느 머리 위를 고칠지 고릅니다. 모양(크기 · 높이 · 배치 · 글자)은 셋이 따로입니다.
- **왼쪽 미리보기** — 내 캐릭터 위에 실제와 같은 코드로 그려 보여 줍니다.
  - 안 걸린 버프 · 쿨은 견본으로 돌려 보여 줍니다(실제 머리 위엔 안 뜸). 미리보기는 참고용이고, 정확한 자리는 게임 화면에서 확인하세요.
  - 비어 있는 줄에는 점선 [버프 넣기] [스킬 쿨 넣기] 칸이 뜹니다. 누르면 바로 고르기가 열립니다.
  - [크기 -] [크기 +] 로 캐릭터 키를 맞추고, [기준점 ▲] [▼] 로 위아래를 옮깁니다.
- **오른쪽 "내 머리 위에 뜨는 것"** — 버프 · CC · 스킬 쿨 · 게이지 / 탈 때(날틀 스킬 · 탈것 스킬 · 날틀) / 그 밖(장비 · 전체 모양) / 갈무리. 누르면 아래 편집칸에서 고칩니다.
- **[띄울 버프 고르기] [띄울 스킬 고르기]** (주황 단추)
  - 이름 일부로 검색하거나, 지금 걸린 것 · 최근 쓴 것에서 고릅니다. 같은 이름은 한꺼번에 잡힙니다.
  - 줄을 누르면 아래에서 **별칭**(짧은 이름) · **색**(스킬)을 정합니다. 오른쪽 [띄우기] / [안 띄우기] 로 켜고 끕니다.
  - 계승자 변형(예: `파열 사격` / `파열 사격: 지진`)은 다 골라 둬도 됩니다. 실제로 쓴 변형을 기억해서 그것만 띄웁니다.

### 줄마다

- **버프** — 아이콘 또는 글자("음식 14:59"), 아이콘 크기, 글자 크기, 높이, 가로 / 세로 배치
- **CC** — 기절 · 침묵 · 발묶임 등을 캐릭터 오른쪽에 따로. [CC 한 번에 등록] 으로 18가지를 한 번에, 모양(아이콘 / 글자) · 글자색 · 크기 · 위치
- **스킬 쿨** — 짧은 이름 + 남은 시간(`파열 12`) 또는 아이콘, 스킬마다 색, 남은 시간 분:초 / 초
- **게이지** — 내 전투 자원(살기 · 운율 · 이성 등), 자원마다 끄기, 크기, 높이
- **날틀 · 날틀 스킬 · 탈것 스킬** — 내 머리 위에만. 탈것 스킬은 내린 뒤에도 남은 쿨이 보입니다
- **장비** — 주무기 · 보조 · 원거리, 아이콘 / 글자
- **대상 거리** — 대상 머리 위, 기준을 넘으면 빨간 글자

### 파티 및 공대

- [전체 켜기] 또는 [선택 켜기](고른 사람만). 파티 · 공대 · 연합을 알아서 찾고, 화면에 보이는 사람 중 띄울 게 있는 사람에게 띄웁니다.
- 팀원 버프 · 팀원 스킬 쿨을 따로 고릅니다.

### 갈무리

- 갈무리(능력 3개)를 1~6번 칸에 등록하면, 갈무리를 바꿀 때 그 칸의 버프 · 스킬 쿨 목록으로 바뀝니다.
- 줄마다 "모든 갈무리 공통 / 갈무리마다 따로 / 골라서 묶기" 를 고릅니다. 쓰지 않으면 목록 하나로 씁니다.

### ESC 메뉴

`[HUD]` 버튼으로 화면의 아이콘만 끄고 켤 수 있습니다. 아이콘을 꺼도 머리 위 표시는 계속됩니다. (통합 일정표가 있으면 이 버튼은 없습니다)

### 채팅 명령 (비상용)

| 명령 | 하는 일 |
|---|---|
| `!bp` | 창 열기/닫기 |
| `!bp reset` | 아이콘을 화면 가운데 근처로 (화면 밖으로 끌어버렸을 때) |

## 알아둘 것

- **상대 · 팀원 스킬 쿨은 기본 쿨**입니다. 쿨 감소 · 쿨 초기화는 알 수 없습니다.
- 상대 · 팀원 스킬은 **전투 기록으로 잡기 때문에** 내 주변에서 쓴 것만 보이고, 허공에 쓴 스킬은 못 잡습니다.
  (내 스킬은 게임에 직접 물어보므로 허공에 써도 뜹니다)
- 전투 자원 게이지 · 장비는 **내 것만** 볼 수 있습니다.
- 업데이트할 때는 `buffplate` 폴더를 **통째로** 덮어쓰세요.
- ArcheRage 전용 스킬 중 검색 목록에 없는 것은 한 번 쓰인 뒤 '최근 쓴 것' 에서 고를 수 있습니다.

## 출처

- `globals` 폴더는 ArcheRage 애드온들이 함께 쓰는 공용 파일입니다.
