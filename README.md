# 이름표 버프 (buffplate)

ArcheRage 애드온입니다. 나와 대상의 **버프·디버프, 스킬·물약 쿨타임, 전투 자원 게이지**를 **이름표 위에** 띄웁니다.
명령어를 외울 필요 없이 창에서 누르기만 하면 됩니다.

## 설치

1. 이 저장소의 `buffplate` 폴더와 `globals` 폴더를 둘 다 아래 폴더에 넣습니다.
   ```
   문서\ArcheRage\Addon\
   ```
   (이미 `globals` 가 있으면 덮어써도 됩니다)
2. 게임에서 `/reloadui` 를 치거나 다시 접속합니다.
3. 화면에 아이콘이 생깁니다. 끌어서 원하는 곳에 두세요.

## 쓰는 법

아이콘을 누르면 창이 열립니다. 위쪽 탭 4개로 나뉩니다.

| 탭 | 무엇을 | 어디에 뜨나 |
|---|---|---|
| **나** | 내 버프·디버프 | 내 이름표 위 |
| **대상** | 대상의 버프·디버프 | 대상 이름표 위 |
| **내 스킬** | 내 스킬·물약 쿨타임 | 내 이름표 위 (따로 한 줄) |
| **상대 스킬** | 대상이 쓴 스킬·물약 쿨타임 | 대상 이름표 위 (따로 한 줄) |

- **목록 줄을 누르면** 이름표 위에 뜹니다. 다시 누르면 내려갑니다. 초록색 `V 띄우는 중` = 띄우는 중.
- **검색칸**에 이름 일부를 치고 엔터 → 게임에 있는 버프/스킬/물약 전체에서 찾습니다.
  싸우기 전에 미리 골라두세요. 같은 이름은 전부 한꺼번에 잡힙니다 (예: "기절"은 스킬마다 다른 기절이 130종).
- **걸린 것 전부 / 쓴 것 전부** 를 켜면 전부 띄우고, 그때 줄을 누르면 그것만 숨깁니다.
- **○○ 표시** 버튼으로 탭마다 따로 끄고 켤 수 있습니다 (버프만 끄고 스킬은 남기기 등).

### 스킬 쿨 표시

- 기본은 **짧은 이름 + 남은 시간** (예: `파열 12`). `[스킬: 이름/아이콘]` 으로 바꿀 수 있습니다.
- **별칭**: 스킬 탭에서 줄을 **오른쪽 클릭** → 검색칸 옆 별칭 칸에 쓰고 엔터 (4글자까지, 비우면 원래대로).
- **스킬 글자** 칸에 숫자(10~40)를 쓰고 엔터 → 글자 크기.
- 계승자 변형(예: `파열 사격`/`파열 사격: 지진`)은 다 체크해 둬도 됩니다. 실제로 쓴 변형을 한 번 맞히면 기억해서 그것만 띄웁니다.

### 그 밖의 설정 (창 아래)

- 아이콘 크기 `작게/크게`, 이름표에서의 높이 `아래로/위로`
- `배치: 가로/세로` — 가로는 옆으로 한 줄, 세로는 기둥으로 쌓기
- `게이지` — 내 전투 자원 게이지(살기·운율·이성 등)를 이름표 위에 막대로 (값이 있을 때만)

### ESC 메뉴

`[이름표버프]` 버튼으로 화면의 아이콘만 끄고 켤 수 있습니다. 아이콘을 꺼도 이름표 표시는 계속됩니다.

### 채팅 명령 (비상용)

| 명령 | 하는 일 |
|---|---|
| `!bp` | 창 열기/닫기 |
| `!bp reset` | 아이콘을 화면 가운데 근처로 (화면 밖으로 끌어버렸을 때) |
| `!bp log` | 진단 기록을 `문서\ArcheRage\Addon\buffplate\debug.txt` 로 (쿨이 안 뜰 때 원인 확인용) |

## 알아둘 것

- **상대 스킬 쿨은 기본 쿨**입니다. 상대의 쿨 감소·쿨 초기화는 알 수 없습니다.
- 상대 스킬은 **전투 기록으로 잡기 때문에** 내 주변에서 쓴 것만 보이고, 허공에 쓴 스킬은 못 잡습니다.
  (내 스킬은 게임에 직접 물어보므로 허공에 써도 뜹니다)
- 전투 자원 게이지는 **내 것만** 볼 수 있습니다.
- 버프·스킬 이름 검색 목록은 게임 데이터에서 뽑은 것입니다. ArcheRage 전용 스킬 중 목록에 없는 것은
  한 번 사용된 뒤 목록의 `최근 봄` 에서 고를 수 있습니다.

## 출처

- 이름표 위에 버프를 띄우는 방식은 **targetdebufftracker (Strawberry)** 에서 착안했습니다.
  창·검색·스킬/물약 쿨·게이지 등 나머지는 새로 만들었습니다.
- `globals` 폴더는 ArcheRage 애드온들이 함께 쓰는 공용 파일입니다.
